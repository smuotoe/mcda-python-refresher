# Python packaging used to be a mess

<div class="grid grid-cols-2 gap-6 mt-1">

<div class="flex flex-col items-center">
<img src="https://imgs.xkcd.com/comics/python_environment.png" alt="xkcd 1987: a tangle of arrows between many Python installs, pip, virtualenvs, Homebrew and Anaconda. Caption: my Python environment has become so degraded that my laptop has been declared a superfund site." class="max-h-80 rounded bg-white p-2" />
<div class="text-xs opacity-60 mt-1">xkcd #1987, "Python Environment" (2018)</div>
</div>

<div class="space-y-3 text-sm">

<div class="px-3 py-2 rounded border-l-4 border-red-500 bg-red-500/10">
<b>"Which pip is this?"</b> <code>pip install</code> went into a different Python than the one running your code.
</div>

<div class="px-3 py-2 rounded border-l-4 border-red-500 bg-red-500/10">
<b>Forgot to activate the venv?</b> You just installed into your system Python.
</div>

<div class="px-3 py-2 rounded border-l-4 border-red-500 bg-red-500/10">
<b>"Works on my machine."</b> <code>requirements.txt</code> without exact versions, so everyone got something different.
</div>

<div class="px-3 py-2 rounded border-l-4 border-red-500 bg-red-500/10">
<b>A tool for every job:</b> pip, venv, pip-tools, pyenv, pipx, Poetry, conda. Each fixed one problem.
</div>

<div class="px-3 py-2 rounded border-l-4 border-red-500 bg-red-500/10">
<b>Slow.</b> Installing a data science stack meant waiting minutes.

# The race: pip vs uv

<div class="grid grid-cols-2 gap-5 mt-1">

<div>

```bash
uv run demos/race.py
```

<div class="text-sm mt-3 space-y-2">
<div>Two fresh environments. pip and uv install the same packages <b>at the same moment</b>:</div>
<div class="font-mono text-xs opacity-80">jupyterlab pandas scikit-learn matplotlib</div>
<div class="opacity-80">106 packages once dependencies are counted.</div>
</div>

<div class="mt-4 px-3 py-2 rounded border border-gray-500/40 bg-gray-500/10 text-xs">
<div><code>uv run demos/race.py --cold</code> makes both ignore their cache: your first-ever install.</div>
<div class="mt-1"><code>uv run demos/race.py requests flask</code> races your own packages.</div>
</div>

</div>

<div>

<div class="font-bold text-emerald-400 text-sm mb-1">Both tools keep a cache. So why is uv faster?</div>

<table class="w-full text-sm border border-gray-600">
<thead>
<tr class="border-b-2 border-emerald-500 bg-emerald-500/20">
<th class="text-left py-1 px-2 border-r border-gray-600">Step</th>
<th class="text-left py-1 px-2 border-r border-gray-600">pip</th>
<th class="text-left py-1 px-2">uv</th>
</tr>
</thead>
<tbody>
<tr class="border-b border-gray-600"><td class="px-2 border-r border-gray-600">download</td><td class="px-2 border-r border-gray-600">skipped (cached)</td><td class="px-2">skipped (cached)</td></tr>
<tr class="border-b border-gray-600"><td class="px-2 border-r border-gray-600">pick versions</td><td class="px-2 border-r border-gray-600">in Python</td><td class="px-2">in Rust, in parallel</td></tr>
<tr><td class="px-2 border-r border-gray-600">install files</td><td class="px-2 border-r border-gray-600">unzip and copy every file, every time</td><td class="px-2">link files it already unpacked</td></tr>
</tbody>
</table>

<div class="mt-3 px-3 py-2 rounded border-l-4 border-emerald-500 bg-emerald-500/10 text-sm">
With both caches warm, the network is out of the picture. What's left is the tool.
</div>

</div>

</div>

# A uv project in four commands

<div class="grid grid-cols-2 gap-5 mt-1">

<div>

```bash
uv init --no-package my-app
cd my-app
uv add pandas
uv run main.py
```

```text
my-app/
├── .python-version   which Python this project uses
├── main.py
├── pyproject.toml    what you asked for
├── uv.lock           exactly what you got
└── .venv/            created for you; never edit it
```

<div class="text-xs opacity-70 mt-1">Also a <code>README.md</code>, <code>.gitignore</code> and a git repo.</div>

</div>

<div>

```toml
# pyproject.toml, after uv add pandas
[project]
name = "my-app"
version = "0.1.0"
requires-python = ">=3.13"
dependencies = [
    "pandas>=3.0.6",
]
```

<div class="mt-2 px-3 py-2 rounded border-l-4 border-emerald-500 bg-emerald-500/10 text-sm">
<b>No activation, ever.</b> <code>uv run</code> creates <code>.venv</code>, syncs it with <code>uv.lock</code>, then runs your code. No more "which pip?"
</div>

<div class="mt-2 text-sm space-y-1">
<div><code>uv remove pandas</code>: take it out again</div>
<div><code>uv sync</code>: make <code>.venv</code> match <code>uv.lock</code> exactly</div>
</div>

</div>

</div>

<div class="sources">
Sources: <a href="https://docs.astral.sh/uv/concepts/projects/init/">docs.astral.sh/uv/concepts/projects/init</a> · <a href="https://docs.astral.sh/uv/concepts/projects/dependencies/">docs.astral.sh/uv/concepts/projects/dependencies</a>
</div>

<!--
[0:14-0:19] Demo live, slowly.

- `uv init --no-package my-app`: pyproject.toml, .python-version, main.py, README.md, .gitignore, and a git repo. (Plain `uv init` in current uv makes a packaged src/ layout; `--no-package` keeps the simple main.py.)

- requires-python comes from the Python uv found; yours may differ. The pandas version is whatever is current when you run it.

# Scripts that bring their own dependencies

<div class="grid grid-cols-2 gap-5 mt-1">

<div>

```python
# /// script
# requires-python = ">=3.12"
# dependencies = [
#     "pyfiglet>=1.0.4",
#     "rich>=15.0.0",
# ]
# ///
import pyfiglet
from rich.console import Console
from rich.panel import Panel

art = pyfiglet.figlet_format("uv", font="slant")
Console().print(Panel(art, border_style="green"))
```

</div>

<div>

```bash
uv init --script banner.py
uv add --script banner.py rich pyfiglet
uv run banner.py
```

<div class="text-sm mt-3 space-y-2">
<div>The <code># /// script</code> block lists what the script needs. <code>uv run</code> reads it, installs those packages into a cached environment of their own, and runs the script.</div>
<div>No project, no venv, no <code>pip install</code>. Send the one file to anyone with uv and it just works.</div>
</div>

<div class="mt-3 px-3 py-2 rounded border-l-4 border-emerald-500 bg-emerald-500/10 text-sm">
<b>You've already seen one:</b> <code>demos/race.py</code> starts with this block. That's why it ran without installing <code>rich</code> first.
</div>

</div>

</div>

<div class="sources">
Sources: <a href="https://peps.python.org/pep-0723/">PEP 723</a> · <a href="https://docs.astral.sh/uv/guides/scripts/">docs.astral.sh/uv/guides/scripts</a>
</div>

<!--
[0:19-0:21] Live, in an empty folder (not inside a project).

- `uv init --script banner.py` writes the `# /// script` block. `uv add --script` fills in dependencies. Open the file and show the block.
- Paste the body from the slide, then `uv run banner.py`: uv installs pyfiglet and rich, then prints the banner.
- Backup if typing goes wrong: `uv run demos/banner.py "Hello, class"` in the repo is the finished version.
- Good for one-off tools, data-cleaning scripts, and anything you share as a single file. For anything bigger, use a project.
- The block follows a Python standard (PEP 723), so it isn't uv-only, but uv is the tool most people use to run it.
-->

<div class="mt-3 text-sm opacity-80">
<code>uvx</code> runs a tool once, in a throwaway environment, without adding it to your project.

<div class="mt-3 px-3 py-2 rounded border-l-4 border-yellow-500 bg-yellow-500/10 text-sm">

<div>

```python
from rich.console import Console
from rich.table import Table


def main() -> None:
    table = Table(title="My Python toolbox")
    table.add_column("Tool", style="cyan")
    table.add_column("What it does")
    table.add_row("uv", "projects and dependencies")
    table.add_row("ruff", "linting and formatting")
    table.add_row("ty", "type checking")
    Console().print(table)


if __name__ == "__main__":
    main()
```
